# 霧旅

走過的地方會從迷霧中解開的旅行地圖原型。

- 水彩風格的迷霧，可切換寫實 / 水彩地圖
- 開始探索後，用手機定位即時解鎖（需保持畫面開啟）
- 記錄店家、飲食、商品、私人地點，附照片、評分、價格與筆記
- 離開常住地自動建立旅程
- 國家徽章，台灣 22 縣市收集；其他國家依一級行政區收集（日本都道府縣、韓國道、美國州…）
- 補登足跡：從照片的位置、GPX / KML 軌跡、Google 地圖時間軸匯入
- 旅程手帳分享圖
- 拉遠看世界：迷霧上畫出國界與經緯線，去過的國家、縣市與地區會亮燈
- 好友：好友碼邀請、好友足跡著色、好友紀錄、即時位置（可逐一開關、可只分享大概位置）

沒登入時，所有足跡與紀錄只存在使用者自己的瀏覽器（IndexedDB）。

登入後（Supabase）：資料備份到雲端，可以加好友、互相看足跡與「好友 / 公開」的紀錄，並逐一選擇要把即時位置分享給哪些好友。存取規則寫在資料庫（Row Level Security）：「只有自己」的紀錄別人讀不到；住家保護區裡的足跡不上傳；足跡只存日期。

地圖資料 © OpenStreetMap 貢獻者，圖磚由 OpenFreeMap 提供。縣市邊界來自 taiwan-atlas（內政部國土測繪中心資料），國界來自 world-atlas，各國行政區來自 Natural Earth。

開發：`npm test` 執行測試。
